# Class icons

The official AION 2 class icons, so the classes look the same as in the game. The
artwork belongs to NCSoft (AION 2).

The files were taken from the game assets shipped with
[Kuroukihime/AIon2-Dps-Meter](https://github.com/Kuroukihime/AIon2-Dps-Meter)
(`AionDpsMeter.UI/Assets/Classes`, commit `5019ef8`, 2026-07-02); `brawler.png` was scaled
down from 812×810 to the 40×42 of the other icons.
